Abstract
  • Web-based library management system for books, students & activities
  • Separate Admin & Student portals with role-based access control
  • Admin: add/edit/delete books, manage members, issue & return books
  • Students: browse, borrow, track due dates & reading recommendations
  • Features: search, filter, notifications, fine calculation & statistics
  • Built with HTML5, CSS3 & JavaScript — fully static, no backend needed
🏗️
System Architecture
  • UI Layer — Dual portal interfaces (Admin & Student)
  • Frontend — HTML5, CSS3, JavaScript ES6+
  • Auth Layer — Role-based login validation
  • Modules — Books, Members, Issue/Return, Fines, Reviews, Seats
  • Data Layer — In-memory JS arrays with CSV export support
  • Deployment — Static hosting via GitHub Pages
